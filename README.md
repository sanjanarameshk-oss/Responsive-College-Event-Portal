# 🎓 Responsive College Event Portal

A responsive college event management portal developed using HTML5, CSS3, and JavaScript.

## 🚀 Live Demo

👉 [View Live Demo](https://github.com/sanjanarameshk-oss/Responsive-College-Event-Portal.git)

## 📌 Project Features

- Responsive homepage
- Event listings
- Event schedule
- Event registration form
- JavaScript form validation
- Event category filtering
- Dynamic announcements
- Event gallery
- Contact form
- Mobile, tablet, and desktop support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- DOM Manipulation
